# Integration 07 | Own-turn boundary expiry: Nature’s Veil

Private Convergence 08-derived source candidate. Source: embedded SRD 5.2.1 printed p. 59, Ranger level 14 Nature’s Veil. Use a Bonus Action to gain Invisible until the end of your next turn; Wisdom modifier uses (minimum one), Long Rest recovery. No other official-book or Avarra-only rules added. Existing NOTICE retained.

## Implementation
- During an active personal combat turn, the existing Nature’s Veil feature action consumes the existing Bonus Action and one use, and atomically adds an independent Invisible source with `expiresOwnTurn = combat.turns + 1`. It survives the activation turn end and next turn start. The next own-turn end removes that source only. Repeated activation can create a later independent expiry; manual sources and other spell sources remain.
- Only the supported fixed feature/condition profile can have this optional integer field, bounded by the personal turn counter. Ledger and combat context validation reject malformed or impossible boundaries. Existing manual same-name sources are not promoted. No change to legacy saved records or database version. Older builds reject new boundary records; do not downgrade. The resource and ledger changes use the existing revision-checked Play Sheet transaction and Undo; no global event receipt was added.
- The turn-end transaction still queues supported Hold saves; it does not advance elapsed game seconds. Starting another turn remains blocked by the existing pending-save guard. The countdown and exact turn-boundary mechanisms are deliberately separate.
- When the personal tracker is not running, the existing resource-only, table-adjudicated Nature’s Veil path remains. While a living character has a timed boundary source, encounter closure is blocked until the duration is processed or DM-confirmed source removal occurs. This is a bookkeeping safeguard, not an SRD rule. For a dead character, closing an encounter detaches the boundary marker and retains its source under table control rather than asserting expiry. Manual source removal remains unavailable while dead (inherited limitation).
- Invisible becomes an effective recorded condition. This is NOT full visibility/attack/targeting automation: the existing attack assistant still requires table-confirmed situational Advantage/Disadvantage. Incoming attacks and visibility exceptions remain table-adjudicated. No general Shield/Dodge/start-of-turn or other-creature boundary implementation yet.
