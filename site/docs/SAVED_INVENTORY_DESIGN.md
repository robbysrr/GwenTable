# Saved-character inventory design

The v0.25.6 development snapshot owns the version 2 `open-5e-companion` IndexedDB database. The roster, builder, Play, and linked GCX actions share a character row. Starting gear and GP normally come from validated `draft` choices. Existing top-level fields may be extension data. The original source archive and the independent v0.25.18 reference remain separate.

- Use one versioned inventory field on the existing row. Store retry receipts alongside it as local metadata. Keep original draft, legacy fields, Play and Undo, GCX, and unrelated extensions. Build saves still derive Strength, size and species traits from the current validated draft. Temporary effects need explicit state in the character model before they can affect capacity.
- Preview original equipment and wallet balances. Use an explicit starter projection for known SRD labels; keep unmatched names at unknown weight. Permit known legacy string lists and integer GP only when there is no competing currency/gear schema. Preserve source values during activation. Active inventory replaces the starter projection for load and equipment displays. Undo activation while it is still unedited, or restore a private pre-activation backup as a separate record.
- Use the existing character transaction and opaque revision for every write. Check duplicates inside that transaction before comparing the revision. New commands require the current revision. Inventory transfers are between locations, containers and wallets of the same character. Catalogue prices apply only to a verified subset. Validate and apply all item/coin changes together.
- Preserve inventory in private character and roster JSON and in a namespaced GCX extension. An existing linked GCX update preserves its local inventory. PDF and Play read the same inventory. Keep receipts and local revision tokens out of portable files.
- Use fresh local browser profiles and synthetic fixtures. The legacy shapes in tests come from the source and are insufficient to certify compatibility with genuine saves.
