# Advanced class-resource gameplay | implementation detail

Candidate GwenTable 0.24.7, SRD 5.2.1 rules reference: `https://www.dndbeyond.com/sources/dnd/br-2024/character-classes` (Paladin level 1, Druid level 2, Monk level 2/10/17). This is a manual gameplay assistant, not a stat-block simulation.

- `dist/lib/play.js` implements deterministic `advancePlay` actions `lay-on-hands`, `wild-shape`, `wild-shape-end`, and `monk-technique`. Counter and HP changes are atomic within an action result and stored under the existing `characters.update()` revision-CAS transaction. No new IndexedDB stores or schema migration. Each action is a single Undo checkpoint.
- `shape:{active,form}` is a new optional persistent Play state. Missing in historical exports defaults to inactive; supplied malformed shape state fails `validatePlay`. The form name is user-provided and escaped in UI. Suggested form names come from the character build; actual known form legality and Beast statistics require DM adjudication. While Wild Shaped, base character calculations are **not** replaced by a Beast stat block; the UI warns accordingly.
- Druid form can end due to incapacitation/0 HP/death. Temporary HP are not pooled or stacked. Ending form does not automatically erase temporary HP. A Short Rest returns one expended use; a Long Rest returns all. The app does not model exact in-world durations.
- Lay On Hands self-healing adjusts this saved character's HP only. Healing/Poisoned removal of another creature consumes Paladin points but must be applied on that creature's own sheet, avoiding invented recipient stats. The ability costs a Bonus Action during tracked combat and refills on Long Rest.
- Monk Flurry/Patient/Step are Bonus Actions during tracked combat and spend Focus Points as appropriate. Levels 10+ gain 3 strikes on Flurry and two Martial Arts dice of temporary HP on paid Patient Defense. Attack rolls, opportunity attacks, Dodge/Disengage movement and saving throws are handled at the table. Level 17+ Martial Arts die corrected to d12.
- Tests: `tests/play-advanced-class-resources.test.js` covers boundary values, exhaustion of pools, turn controls, malformed backups, Legacy Play, single-character portability, and restoring Undo snapshots. Run `npm test` to reproduce.

**Known scope limits:** This is not a comprehensive Druid beast statblock engine, spellcaster-in-form rules simulator, Monk Stunning Strike or Paladin smite calculator. High-level class progression and original-source licensing still require separate verification. Real-browser, mobile, PDF print and screen-reader acceptance are pending.
