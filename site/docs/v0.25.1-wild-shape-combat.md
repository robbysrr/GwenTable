# GwenTable v0.25.1: Verified SRD Beast combat integration

Local implementation candidate, 19 November 2026. This release is **not approved for publication**.

## What was implemented

1. `dist/lib/beast-combat.js` is a deterministic rules engine for **11** hand-reviewed SRD 5.2.1 Beast forms: Wolf, Panther, Boar, Giant Badger, Giant Crab, Giant Wolf Spider, Giant Venomous Snake, Brown Bear, Tiger, Giant Spider, and Giant Toad. The source index and relevant SRD Animals pages are tested against the selected form data.
2. When a legal, supported Wild Shape is active, the Play Sheet now displays the form's own AC, reference HP, walk/climb/swim/burrow speeds (rendered in the app's metric display), listed attacks, typed dice expressions and conditional traits/effects. Stat blocks remain *reference values*, not mutations of base Druid scores/HP. The Druid retains its own actual HP.
3. An attack action asks for target AC or explicit DM hit confirmation, handles Advantage/Disadvantage, natural 1/20, Exhaustion and two-damage-type attacks. A critical hit doubles **each dice component** while flat modifiers are applied once. Only confirmed hits generate damage rolls. The engine does not guess enemy AC or update enemy HP.
4. Every accepted Beast attack enters the same revision-protected Play save and log as other player actions, and is available to existing one-step Undo and private JSON backups. Damage effects, Grappled/Prone, Web recharge, Multiattack action count, out-of-turn triggers, cover, immunity/resistance and target saving throws remain DM-controlled.
5. `dist/lib/beast-reference.js` now excludes **Giant Owl** as a normal SRD Wild Shape Beast because the SRD 5.2.1 Giant Owl is a **Celestial**. The Giant Eagle is also a Celestial and was already outside the recognized Beast whitelist. Unrecognized/DM-approved forms remain accessible via the manual workflow, but never receive invented automatic statistics.
6. Localized button, warnings and headings are provided in both English and Bahasa Indonesia. Flag language toggle and all prior gameplay features are preserved. Offline service worker revision `open-5e-v0.25.1` precaches the new module.

## Explicit constraints

- Supports only the 11 curated forms. This is **not** a complete or dynamic Beast compendium parser.
- The engine intentionally does not automatically replace base character-sheet ability scores, AC or speeds, and does not manage external target HP. The UI's active Beast reference provides those reference values separately.
- The official SRD Animals blocks are the source of the listed melee hit bonuses, core damage dice and type labels. Conditional extra damage (e.g., Boar's charge), Web and Swallow are reminders only. These are not calculated automatically.
- Level-8 Circle of the Land Druid allows the curated CR 1 forms; at level 2/4 those forms are not automatically authorized. Other subclass limitations are not assumed.
- This is not a migration: existing Play data and backup structures have not changed. Previous characters may use the new feature if their Wild Shape form has a supported verified profile.
- No real browser, mobile, keyboard or screen-reader acceptance was completed in this environment.

## Source traceability

The packaged index `dist/lib/creatures.js` provides source pages and AC/HP/CR; `dist/lib/srd-reader-pages.js` contains source-page text. Relevant 2024 Animals page numbers: Boar and Brown Bear 346; Giant Badger 349; Giant Crab 350; Giant Spider 353–354; Giant Toad and Giant Venomous Snake 354; Giant Wolf Spider 355; Panther 358; Tiger 363; Wolf 364; Giant Owl 352 and Giant Eagle 350 (both Celestials). External official reference: https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf.
