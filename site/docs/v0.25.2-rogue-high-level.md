# GwenTable v0.25.2: SRD 5.2.1 Rogue/Thief level 13–20

## Scope and evidence

Baseline: v0.25.1 full source (414 automated tests). Targeted extension: Rogue (Thief) to 20; all existing gameplay actions, storage schemas and other class caps are preserved. Primary class reference: [D&D Beyond Basic Rules 2024 Character Classes](https://www.dndbeyond.com/sources/dnd/br-2024/character-classes) and [SRD CC 5.2.1](https://media.dndbeyond.com/compendium-images/srd/5.2/SRD_CC_v5.2.1.pdf).

## Implemented

* `levelsFor('Rogue')` now permits 1–20. All other non-Fighter classes remain 1–12. High-level Rogue creation generates feat/ASI at 16 and Epic Boon feat with permitted +1 ability score at 19, with validation, level-scaled HP, proficiency, XP and skill calculations.
* Rogue Sneak Attack display and attack-resolution dice both use the increasing 1–10d6 progression. Level 15 Slippery Mind adds Wisdom and Charisma saving throw proficiency; level 3 Thief climbing speed is reflected as the character's speed.
* Thief features unlock at 13 (Use Magic Device), 17 (Thief's Reflexes), plus Rogue 14 Devious Strikes, level 18 Elusive and level 20 Stroke of Luck. A DM-dependent effect is explained, not silently executed.
* Cunning Strike supports two distinct chosen effects from level 11, with legal costs and level 14 Daze (2d6), Knock Out (6d6) and Obscure (3d6). Costs subtract from Sneak Attack dice before a critical hit doubles the remaining dice. Poisons require kit confirmation; Trip requires a legal target size. The app does not assign external conditions or target HP.
* Stroke of Luck records a confirmed failed D20 Test transformed to 20, once per Short/Long Rest. Its player-activated button uses the existing revision-protected Play/Undo save path. Level 19 Boon of Fate resource tracking now applies to eligible Rogues, not only Fighters.
* UI includes English and natural Bahasa Indonesia labels; v0.25.2 service worker cache is independently versioned, including an artwork-withheld QA preview.

## Verified automated evidence

* 430/430 Node tests pass (16 added over v0.25.1), including 800 deterministic level-13–20 Rogue generated builds.
* Tests check progression, XP, saving throws, feat validation, high-level resource recovery, Cunning Strike rules, critical hits, malicious/inconsistent inputs, undo, backup compatibility and UI hooks.
* `npm run build` is a static/source/reference check, not full production bundling. Unit and simulated tests do not substitute for real-browser acceptance.

## Explicit boundaries

1. **No all-class 20-level claim:** only Fighter and Rogue reach level 20; spellcaster high-level preparation, subclass and magic dependency integration is not complete.
2. **No automatic target conditions or magic-item engine:** Use Magic Device/Elusive/Thief's Reflexes produce accurate guidance; target effects, enemy saving throws, target HP, attunement and initiative sequencing remain DM/player decisions.
3. **Not publication approved:** real Chromium/mobile/touch/assistive-technology testing remains open. 12 inherited artwork files are still not cleared for public distribution; the withheld preview is QA-only.
4. **No deployed changes:** source archive and patch are separate from a connected canonical Git remote or live website.
